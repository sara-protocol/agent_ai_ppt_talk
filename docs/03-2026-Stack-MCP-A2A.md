## A2A
- 網線，Agent ↔ Agent
- Google 2025-04推出，2026-03 v1.0，150+組織
- 原語: Agent Card, Task 8狀態, Transport JSON-RPC+SSE
- IBM ACP於2025-08合併入A2A

一句話: MCP connects agents to capabilities. A2A connects agents to agents.
